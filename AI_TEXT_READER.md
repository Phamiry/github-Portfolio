# AI Text Reader — Jaylon Pham

**Project showcase:** [Phamiry/artificial-intelligence-project](https://github.com/Phamiry/artificial-intelligence-project)

## Overview

I contributed to a Python application that converts text to speech through the ElevenLabs API. The command-line program accepts direct text input or reads text from a file, generates an audio response, plays it, and saves an MP3 file.

## Tools

Python, ElevenLabs client SDK / API, FFmpeg (installation prerequisite).
